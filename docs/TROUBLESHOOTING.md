# Troubleshooting

**"App not installed as package conflicts with an existing package"**
Another app with package `com.termux` (or an add-on sharing its user id) still exists, possibly hidden.
Uninstall Termux **and** Termux:API / Styling / Boot / Widget / Float / Tasker, check *Clone apps / Dual apps /
Second space* (Oppo, Realme, Xiaomi…), then *Settings → Apps → ⋮ → Show system apps* and search for `termux`.
Install from the file manager after extracting the zip (don't install from inside the zip preview).

**Play Protect blocks it** – the APK is signed with a test key. Choose "Install anyway", or pause Play Protect scanning.

**Arabic still looks wrong** – open an issue with a screenshot and the exact text/program.
